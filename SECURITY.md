# CMC Network Security Policy

**Last updated:** 26 September 2026

Creative Minds Network takes the integrity of its code, brand, and user trust seriously.

---

## Reporting a security issue

If you discover a security vulnerability in the public site or suspect unauthorized access to this repository, please contact the repository owner privately.

- Do **not** open a public issue.
- Do **not** include exploit code, credentials, or access details in public comments.
- Provide a clear description of the issue, steps to reproduce, and potential impact.

We will respond as quickly as possible during business hours.

---

## Reporting unauthorized copying or abuse

If you see this code, design, or content being used elsewhere without permission:

1. Collect evidence (URL, screenshots, commit references).
2. Contact the repository owner privately.
3. We will pursue takedown or legal action as appropriate.

---

## Public site scope

The live GitHub Pages deployment is a static demo/marketing site. It does not process real payments, collect student data, or authenticate users. Any forms simulate submission for demonstration purposes.

---

## No bug bounty

We do not operate a bug-bounty program for this repository. Responsible disclosure is appreciated.
