# CMC Network Contribution Policy

**Effective date:** 26 September 2026  
**Applies to:** All visitors, users, collaborators, and third-party developers

---

## TL;DR

**This repository is not open source. Contributions, forks, clones, and derivative works are not allowed without explicit written permission from the owner.**

---

## 1. No External Contributions

Creative Minds Network does **not** accept unsolicited:

- Pull requests
- Code patches
- New content submissions (worksheets, questions, descriptions, translations)
- Design changes
- Feature requests that include code
- Embedded code or assets in issues

If you have a high-priority bug report that affects the public site, you may open a GitHub issue **without including code, designs, or proprietary suggestions**.

---

## 2. No Cloning, Remaking, or Repurposing

You may **not**:

- Fork or clone this repository to your own account.
- Recreate or remake the games, tools, layout, or interactive features shown on the site.
- Add content to this site or to any copy, mirror, or derivative version.
- Use any part of the code, design, or wording in your own projects, apps, games, or websites.

The code, design system, educational content, and branding are protected under copyright, trade dress, and related laws.

---

## 3. Protected Assets

The following are strictly protected and may not be copied or reused:

- React components and TypeScript logic
- Tailwind CSS utility classes and custom animations
- Landing page copy, marketing claims, and value propositions
- Curriculum-aligned resource descriptions and sample questions
- Pricing tables, FAQ content, and testimonial-style copy
- The CMC Network name, logo stylization, and visual identity

---

## 4. Reporting Security or Abuse Issues

If you discover a vulnerability, unauthorized copying, or abuse of this repository, please contact the repository owner privately. Do **not** open a public issue containing exploit details.

See [`SECURITY.md`](./SECURITY.md) for responsible disclosure guidance.

---

## 5. Violations

Violations of this policy may result in:

- Takedown requests to GitHub or hosting providers
- Legal action for copyright and trade dress infringement
- Reported abuse under GitHub’s Terms of Service

---

## 6. Authorized Collaborators Only

Only individuals with a signed written agreement or explicit written
authorization from Creative Minds Network may contribute to or manage this
repository.

---

Thank you for respecting our work.
